# Leotv 5.1.28 / 538：原生折叠、分类切换与回顶

用户反馈切换分类会重新唤醒已经折叠的顶栏，顶部闪入分类内容，一键回顶后列表和分类栏之间出现额外空隙。

GlobalChrome 的旧分类切换分支仍在重置所有缓存页面的滚动位置并主动调用 setExpanded(true)。这两条路径现已删除；分类切换只由原 pager 和宿主管理，保留原 AppBar 的折叠状态及每个分类的原生列表位置。

之前只给当前屏幕中心的分类适配顶部 padding，滑动中的邻页会在未经适配时进入画面，产生真实卡片闪入透明顶栏的现象。现对 pager 中已测量的缓存页提前处理顶部避让，支持原 pager 使用的普通 LayoutParams，不限于 MarginLayoutParams。需要重排时先完成布局再绘制，分页容器保留边界裁剪；不复用上一分类图像或回放内容。

原顶部 padding 始终采用完整 AppBar 高度，即使工具栏已隐藏仍保留那一段高度。现在列表真正位于起点或首次适配时，使用 AppBar 当前屏幕上的可见底边对齐；正在滚动的列表保留既有锚点和 padding，避免折叠过程中不断重排内容。回顶继续使用原按钮和原滚动动作，保留原列表自身的正常间距。

定向检查覆盖：普通 pager LayoutParams 的两个缓存页面在横滑前均完成适配，顶栏折叠状态和前页滚动位置不变，透明顶栏区域没有未经避让的邻页卡片；回顶后的列表起点与实际可见分类栏边缘对齐。测试使用虚构卡片和原生 View，不读取用户数据。

三态玻璃按钮、状态栏浅遮罩、TV 平滑轮播和续播刷新保留；上下栏实时模糊/内容回放继续关闭。GitHub 按既有四变体原样基准、API 23 编译、精确变化审计与固定 APK 签名交付，实际触摸与画面由用户真机验收。
