## 已授权范围与最新约束

- 手机底栏保留现有视频、追更、直播及设置动作；图标使用参考的首页、日历、播放叠框、设置外形，选中键停驻后保持蓝色。
- 修复启动期间原生菜单隐藏、后加追更独自显示的问题。追更与原有菜单就绪状态同步；保留无直播配置时原生直播项的可见性策略。
- 主面板需要能一眼辨认的玻璃质感，保持背景透光；最后一次调整提高面板的磨砂和反光，水滴继续接近透明，避免灰色填充块。
- 水滴用背景透镜折射、薄边高光、局部反射及极淡聚光阴影表现凸起；运动时前端鼓起、尾部收窄、轮廓轻微波动，停稳后收敛。形变属于本工程的近似实现，不声称恢复了 IPA 的完整 Dart 源码或原始运动参数。
- 中心对准按钮范围，快速切换也不冲出首尾中心。典型四项底栏左右最多约 6dp 外圈、60dp 底栏的动画水滴最多 80dp 高，允许上下超过底栏。
- 手机回顶、筛选和分类快捷筛选，以及 TV 左侧六项快捷按钮同步材质与触感 / 焦点反馈；保留原生图标动作、长按、遥控焦点记忆与返回内容路径。
- 新增手机底栏自动收起：识别内容拖动 / 翻页时向下隐藏，原生滚动回调维持惯性阶段，停止约 180ms 后从底部弹回。只移动底栏，不改列表尺寸与底部留白；按钮点击不触发该策略。离开窗口停止动画和延迟回调。

## 草稿实现与核对边界

主要改动：`ui/java/com/leotv/ui/PhoneGlassChrome.java`、`LiquidGlassButton.java`、`GlobalChrome.java`、`NativePhoneInsets.java`、`ProgressiveBlur.java`。分类 / 回顶的两处自有 ImageView 添加材质标记，位于 `NativeCspUi.java`、`CspHomePage.java`，不重建其点击动作。没有导入 IPA 二进制、iOS / Flutter 运行时或新 native 库。

运行方式为原生 Canvas、有限范围采样、共享分离盒模糊与有限透镜网格，按 API23 接口编写。底栏水滴、滚动可见性和按键焦点分别持有有限动画回调，暂停时释放；原有播放器、订阅、数据库和 ABI 交付范围不变。

`research/ui-check` 覆盖整组菜单就绪、原生动作保留、取消与长按、快速重定向、形变边界、接近透明的水滴填充、拖动收起及上弹、暂停释放。此前缺少的新主页测试签名、初始化及扫码清理占位已补齐；测试同步 Activity 焦点并显式推进暂停的动画帧。22 项检查已在 GitHub CI 通过；APK 的 API23 编译和签名核对通过，实际 Android 6 设备运行与视觉验收仍待用户完成。
