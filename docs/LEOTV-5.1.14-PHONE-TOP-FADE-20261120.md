# Leotv 5.1.14 手机顶部淡出与原生布局

用户真机反馈 5.1.13 底栏切换分类已无残影，但手机顶部和设置内容整体下移，内容区、顶部模糊仍有横向分界。按本轮要求移除手机顶部模糊，改为内容滚至原生状态栏附近的短淡出；继续修改后推送 GitHub 构建，跳过回归套件。

- 对照普通手机 `P3/b.smali` 的 `onCreate(Bundle)`，宿主原本已调用原生 edge-to-edge 实现并分发系统栏 inset。5.1.13 退出线路内容时却强制设置 decor fitting 为 true，重新避让系统栏；再次进入还会叠加 root padding 补偿。手机现在由原生基类完整管理窗口 fitting、布局标志、系统栏及根 padding，内容、设置、播放之间不切换这些参数。TV 分支保留既有行为。
- 手机 Portal 不再调用顶部 Band，也不采样模糊、复制顶部内容矩形或重绘顶部控件。只绘制当前宿主背景，在状态栏下沿上方 4dp 至下方 6dp 之间以平滑 alpha 曲线渐隐；过渡下方完全透明。渐变掩码按几何变化缓存，无顶部图像缓存。
- 推荐页的 ScrollView/NestedScrollView 与其他分类的 RecyclerView 均使用原 viewport 扩展方式，释放当前滚动页到 content 之间的祖先裁剪，使真实内容可以画到原生状态栏；原列表 adapter、滚动事件和 AppBar 折叠逻辑保留。退出内容页恢复列表尺寸/padding 与祖先裁剪。
- 透明 AppBar 使用原生 Z 顺序保持在内容前方，暂时移除 outline 以免引入下沿阴影。离开内容、切换原生控件及销毁时恢复原 Z 和 outline。无需用顶部内容条遮盖原生画面。
- 底栏绘制、分类归位、详情/播放器衔接以及 TV 顶部效果保持既有代码。仅修改允许的 `GlobalChrome` 覆盖类及其内部类；版本为 5.1.14 / 524，未改动原始 smali、数据库、协议、原生库和用户配置。

本轮未运行本地/CI 回归套件，GitHub 执行四变体 API 23 编译、基准/变更审计、固定签名和发布检查。顶部观感、原生折叠、设置位置及推荐/其他分类的完整滚动由用户真机验收，不宣称已通过设备测试。
