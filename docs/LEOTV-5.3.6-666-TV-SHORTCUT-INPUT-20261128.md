# Leotv 5.3.6 / 666 TV 快捷菜单遥控修复

用户真机反馈 665 修改玻璃 UI 后，TV 左侧快捷按钮能够唤醒，但不能移动或点击，方向操作会退出菜单。按用户要求，优先修复并交付此问题；浪壳全局迁移保留本地草稿，未进入这次构建源集。

## 修复范围

- 旧按键分支仅在快捷菜单 `hasFocus()` 时运行；菜单显示但焦点被内容更新取回时，遥控事件会继续进入首页。现在以菜单的实际显示状态维持按键归属，失焦后恢复上次选中按钮，再处理上下移动。顶部/底部停留在边界，左键保持菜单。
- 确认/Enter/数字 Enter 的按下、重复、抬起都由菜单消费；仅未取消、按钮未变化且仍启用的抬起执行一次已有 `performClick()`，避免原首页收到确认事件。右键/返回维持原关闭菜单并回到内容的行为。
- 玻璃背景采样以前临时把按钮 alpha 设为 0。现在在独立采样遍历中排除目标按钮与整组 TV 菜单，不改控件 alpha、可见性或焦点，也避免玻璃重复进入自身采样。
- 六个按钮的原操作、焦点记忆、手机玻璃底栏、播放器、配置、数据库、API23 和八套完整/基础交付保持。

## 核对与交付

补充实际 UI 检查：可见菜单失焦后的上下/左键归属、确认长按重复只触发一次、取消确认不点击、右键/返回恢复内容，以及采样不写入控件 alpha。原 UI 检查和必需源码/API23/R8/原样/变化/native/固定签名门禁继续执行。没有本地打包 APK；运行效果由用户 TV 真机验收。
