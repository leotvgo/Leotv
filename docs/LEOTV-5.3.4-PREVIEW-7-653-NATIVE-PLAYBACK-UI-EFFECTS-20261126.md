# 5.3.4-preview.7 / 653：原生播放设置、VLC交接与TV滚动

本轮按用户后续确认落实：MPV保留原共用弹幕加载；移除独立字幕编辑及后台/线路设置，恢复原生字幕预设，修正解码行间距；修复TV VLC切换黑屏和退出延迟；检查各TV详情主题的上下遥控卡顿/海报抖动；增加不同结构与颜色的特效底板及随机叠加花瓣，提高双光点/花瓣占比。另一个窗口的新主页主题、影视库海报/卡片和原生回收列表源码一并合并，初始视口未完成部分接续收尾。保留此前已验收的MPV/VLC播放、原容器和八种头像，不增加上下跳动。

## MPV原生设置与字幕

MPV专属列表仅为解码、MPV配置、着色器三行。原字幕预设/系统样式和弹幕加载继续走共用项；后台/线路播放隐藏配置行，执行原生后台/PiP与自动线路协议，不改写其他内核的全局保存值。第一行改用原解码行模板的16dp间距，恢复与播放核心的距离。

不再读取旧独立字体、字号、颜色、ASS覆盖、字幕/音频延迟表单值；保留其导入文件和存储，避免删除用户数据。`sub-ass-override=no`、`embeddedfonts=yes`使ASS样式、定位、卡拉OK及媒体嵌入字体由libass原生处理，字幕类型不变。原“系统”字幕预设在选择时接入CaptioningManager的缩放/颜色/描边；默认“预设”使用内核默认值，不额外覆盖文件样式。固定libass没有必需系统字体provider，最多复制一份系统Latin和CJK回退字体供未嵌入字体使用，不扫描加载全部字体，也不选择此前自定义字体。读取系统TTF/OTF/TTC的真实family作为缺省回退；固定libass没有字体provider时不能靠“sans-serif”自动匹配Noto/Droid。该回退只解决未提供字体的字形覆盖，文件原有ASS样式/嵌入字体仍优先。

## VLC异步清理与接管

旧实现主线程连续 `detachViews → player.stop/release → proxy.close → lib.release`，慢读/解码释放会拖住退出，切核没有清理完成边界。现在先清除事件引用、关闭本地代理端点并在主线程解绑视图；native播放器和库在串行后台队列释放，远端连接清理独立执行。退出立即移除VLC视图。

原 `C3.e.j0` 加入清理完成门禁，旧解码器释放后再回到完整原加载流程，保留原时间、弹幕、媒体会话尾部。每个请求绑定当前会话/内核/媒体标识及序号，替换、退出、重新绑定会取消旧请求。切核先保存原History的选择和进度，显式恢复原Exo/IJK视图。Java/native固定输入不变；所有Window操作仍在主线程。虚构生产bridge/engine契约验证后台阻塞时退出能返回、原视图/URL/headers接管、请求替换和退出取消；这不是设备播放认证。

## TV各详情主题

共用TvDetailScroll/Navigation不再为同一在途目标取消并重启240ms动画；遥控可见区域按最终目标计算，避免半屏固定海报的过渡状态反复改变滚动目的地。框架焦点/尺寸滚动不能覆盖显式遥控位置；主视觉内的动作回到完整主视觉。滚动时延后影视库信息测量/容器高度变化，结束后统一同步；仅为不超过2M像素且边长2048的硬件主视觉临时借用图层，取消/结束/释放归还。首次视口仍保护回顶与原播放按钮，真实导航后解除，不阻断原触摸/内容更新。

上述路径覆盖经典、光影、极简、雷霆和影视库详情主题。与另一窗口原生两层首页回收、手机影视库竖版海报、横屏资料/按钮上移及同类卡片样式一起交付，详见原[合并范围](LEOTV-HOME-THEMES-LIBRARY-RECYCLING-20261126.md)。

## 随机炫彩组合

保留原胶囊，新增圆角卡片、对话气泡、票券边、切角徽章五类底板结构；配合冷暖/通透/柔彩渐变、多色边框和双线样式。双光点增加红蓝、绿金等配色与白色亮芯。花瓣有独立样式，也可随机叠加其他底板、光点、表情、头像，组合按评论token确定，重绘不反复换样。

整体特效比例仍采用用户设置、默认15%。在选中特效中双光点和花瓣各占3/13，其他七类各1/13；其他样式和八种头像保留。叠加花瓣也共享原计时器及单动画上限，图案和路径只在缓存创建时生成；头像/文字仍计入2MiB，辅助key限制64项。没有新的弹幕容器、动画线程或整体上下跳动。
