# 5.2.6 / 625 正式版：TV 详情返回回顶并聚焦播放

用户在 5.2.5 构建期间要求停止等待流水线，直接增加 TV 详情页返回回顶并发布正式版本 5.2.6。沿用 5.2.5 已提交的弹幕 API 入口、原生站源开关、TV 新主页返回/分类复位及播放按钮反馈调整。

TV 详情从选集、底部内容或任何非播放焦点处按返回，在抬起且事件未取消时先通过 `navigation.focusPrimary()` 定位顶部播放按钮，并调用原 `scroll.position(0,false)` 即时回顶、停止旧滚动动画。详情已在顶部且播放按钮拥有实际焦点时，再按返回退出详情。回顶恢复遥控导航模式，后续布局稳定仍以播放按钮为目标。

返回优先级保持：原选集窗口先关闭，站点选择先按已有规则收回，人物等弹窗仍先处理自己的返回；只有详情内容进入本次回顶分支。手机返回退出行为保持。当前来源、选集、续播、下载及播放回调不作改变。

源码改动限定于 `TvDetailPage` 的 TV 返回分支、`TvDetailNavigation.focusPrimary` 的遥控状态、版本/交付说明。versionName=5.2.6、versionCode=625、stable、非预发行、Latest；R8 8.8.34 release/full、API23、原样/变化审计、双 ABI 原生资产和固定 APK 专用签名照常。内部 mapping 不进入正式 APK 下载。

按用户要求不运行本地打包或额外回归，直接推送触发 GitHub 构建及自动正式发布；不阻塞对话等待构建完成。沿用本会话临时公开构建授权，交付结束后恢复私有。真机回顶、弹窗优先级及播放焦点待用户验收。
