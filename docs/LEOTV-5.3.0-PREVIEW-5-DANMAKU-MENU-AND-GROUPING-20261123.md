# 5.3.0-preview.5 / 617：原生弹幕入口、来源与选集归类

用户确认 preview.4 手机左侧搜索已出现，明确要求移除手机/TV 动作栏额外“弹幕搜索”文字按钮；原“弹幕”按钮及其事件保留。手机搜索图标复用原生小电视/弹字轮廓，按用户最后澄清把搜索角标放在右下角。用户要求修复完整剧集错误进入来源分组的问题、自动匹配，并细化搜索窗口布局；代码定位完成后直接 GitHub 构建，不重复本地测试或打包，由用户真机验收。

## 原生动作与手机菜单

对照 TV 两个 ABI 的原 smali 及当前覆盖层：VideoActivity.K 中原点击/长按和上下监听绑定保持；CustomUpDownView、原点击/长按回调和 E3.d 渲染器未被覆盖。M.a/c 的原上下处理保持，原延迟步长为 1 秒、范围 ±120 秒、延后应用 1500ms；原行数/延迟模式保持。API 会话的播放结果/首次准备/换集挂接是新增调用，不替换这些原生方法体。证据见 `evidence/leotv-tv-native-danmaku-events-20261123.json`。

手机旧挂接定位错误：大写 R3/P 读取 Player.u 的字幕列表，A0 为 v3/a；真正弹幕菜单为小写 R3/p，Git 路径 `smali/R3/p.1.smali`，A0 为 w3/k，初始化读取 Player.s 的弹幕来源。现在改接真正的弹幕来源菜单，原字幕菜单恢复原字节码。源码锁记录正确文件 SHA-256，ABI 门禁新增菜单必须读取 Danmaku 来源列表的检查，防止只按相似字段匹配错类。

原来源列表、文件选择、显示开关、原生设置和播放器接口保留。手机侧边保留直接搜索；两端菜单追加的 API 搜索和显示开关保留。

## 图标与搜索布局

图标使用普通原 APK `drawable/ic_control_danmu_on` 的首条路径，保留原生电视及弹字，替换原右下角状态标记为放大镜。使用 API23 Drawable/Path，沿用原侧边控件尺寸、padding 和点击样式，不添加图片资源或第三方库。来源记录见 `evidence/leotv-danmaku-search-icon-source-20261123.json`。

来源识别原正则把 `from iqiyi - 【qiyi】 剧名第N集` 整段当作来源名，导致每集成为一个来源页签。现在来源只取平台部分；同来源下仍按作品分组、剧集进入网格。保留原 API 目录 ID、剧集 ID 及地址。

搜索窗口把标题、输入、排序及平台页签固定在选集滚动区之外，避免焦点滚动把上方控件推走。统一间距、弱底色与焦点边框，剧集用紧凑网格，默认展开最接近搜索词的作品；搜索后收起键盘。没有新增筛选、设置项或播放器布局。

## 自动匹配

自动分支现在读取与手动分支相同的目录；只有作品目录时会在后台读取剧集，再按当前集数选择实际弹幕条目，不依赖打开窗口或点击展开。未解析目录不作为可播放弹幕。匹配优先读显示的剧集文字，再回退显式编号，避免编号与显示集数不一致时只选首集。

加载/自动开关、当前 API 和“站点弹幕优先”策略保持。旧请求的 Activity、剧集及 API 所属检查保持；用户主动选择原来源仍接管播放，不被旧自动回调覆盖。
