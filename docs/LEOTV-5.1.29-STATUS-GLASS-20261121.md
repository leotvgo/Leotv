# Leotv 5.1.29 / 539：手机状态栏渐变玻璃遮罩

用户确认 5.1.28 基本符合预期，本轮仅调整手机原生状态栏遮罩的材质，并要求直接推送构建，视觉与交互由用户真机验收。

NativePhoneInsets.StatusShade 将原整段 0x33 浅暗色改为底栏 NavigationGlass 同色系的渐变玻璃：窗口最上端透明，逐步叠加半透明白光，到状态栏末端过渡为 0x45 的蓝灰磨砂色；原有 8dp 尾部柔和淡出到透明，避免直线接缝。材质通过静态多段 LinearGradient 营造渐变磨砂观感，和现有底栏一样不对下层内容做实时图像模糊。

遮罩仍是原 View、原 tag、原位置与层次，高度仍为原状态栏范围加 8dp；绘制严格落在原 Drawable bounds 内。未调整顶栏 padding、列表/分类避让、折叠、回顶、导航、悬浮按钮或任何 TV 布局。Shader 仅在 bounds 变化时创建，不新增图像采样、内容回放或周期绘图回调。只改动既有 NativePhoneInsets$StatusShade 的绘制实现，无新增类或图片资源；该类继续使用现有覆盖层类门禁。版本元数据更新至 5.1.29 / 539。

现有状态遮罩门禁同步为透明起点、渐增半透、尾部淡出及原尺寸约束。本轮按用户要求不运行本地构建、回归测试或设备验证，GitHub 构建使用 run_validation_tests=false；既有 APK 构建审计、API 23 编译、四变体与固定 APK 签名交付步骤保留。实际效果待用户真机验收。
