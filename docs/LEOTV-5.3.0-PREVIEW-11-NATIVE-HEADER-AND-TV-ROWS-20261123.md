# 5.3.0-preview.11 / 623：原生站源开关、TV 返回与设置间距

用户要求移除 TV 个性设置的重复弹幕 API 入口，对齐原弹幕设置中新增行的间距；手机新主页恢复原“显示站源”开关控制，并明确删除换站后站名显示 4 秒、自动切搜索胶囊的附加逻辑。TV 新主页返回应先到所在分类的第一个作品，再到顶部，离开视图的分类行应复位。用户同时报告 TV 详情播放按钮按下反馈有停顿，要求优化。

## 弹幕设置

`Personalization` 仅取消 TV 的第三排弹幕 API 入口及空排，手机原入口保留。用户随后要求原弹幕设置中的入口改名为“弹幕API”、放到第一项。`DanmakuUi.attach` 继续复制原 `danmuLoad` 样式，新 API 首项不增加上边距，原加载项顺延为第二项并取得相邻设置行的 16dp topMargin，其余原项目的相对顺序保持。API 弹窗标题同步改为“弹幕API”，其中加载/自动匹配/站点优先等配置与动作保留。手机设置行标题同步，顺序沿用原位置。

## 手机站源和搜索胶囊

原 `S3.G.x0()` 读取 `H6.l.n0()`，后者读取原 SharedPreferences 的 `home_display_name`，默认 true。x0 根据该开关控制 `searchInput`、`title`、`searchIcon`，下载入口也继续遵循原 `builtin_download`。

新主页删除 `phoneSiteUntil`、4 秒延时、直接设定上述控件 visibility 的代码。借用及再次布局同步时调用原 `S3.G.x0()`，保留原点击监听、热门词和顶栏接线；换站或从设置返回时仍执行原生设置刷新，不新增另一个控制开关或定时状态。四变体 ABI 门禁新增对手机 `S3.G.x0()V` 的核对。旧 4 秒强制切换专用测试因用户明确删除该行为而移除，不运行本地回归。

## TV 返回和分类行复位

返回键仍按一次按下/抬起处理。在分类第 2 个及以后卡片或行尾更多上，返回抬起先让该行第一个实际卡片获取焦点；在首项再返回才进入原 `focusSite` 回顶。分类显示数量、更多动作、左右移动及原生卡片样式保留。

纵向滚动时仅复位完全离开视口且不持有焦点的分类行：横向位置回零、选中索引归零、清理旧焦点引用。再次进入已复位行从第一个卡片开始；仍在视口内的行保留现有导航。退出首页时也复位 TV 分类行，并保留纵向页面位置。异步填充/尺寸刷新不再将已复位行的旧横向坐标写回，停用页面期间不执行旧焦点滚动。手机分类滚动不作本次改变。

## TV 播放按钮反馈

`DetailPlayButton` 将颜色与缩放放进同一个 ValueAnimator，从当前实际颜色/缩放衔接下一状态，避免短按时两条动画分别中断、计时不同步。TV 按下为 70ms、释放/焦点为 120ms，使用减速插值；窗口失焦清理按下和中途动画状态。绘制继续使用原测量框内缩放，不引起布局变化，也不添加播放等待。手机保留原颜色、90/160ms 时长及原插值。

此项属于视觉反馈优化，没有真机帧耗时测量，顺滑度及播放启动反馈仍由用户设备验收；不将构建成功当作运行流畅性证明。

## 构建和审计

修改限定为上述六个 UI 类、版本标识、新增原生 ABI 核对及删除的旧行为测试。原 smali、资源表、ZIP 资产、数据库、JNI/反射接口、Android 6 回移层和双 ABI 原生库保持。源码门禁、API23/R8、原样/变化审计和固定签名保留；按用户要求关闭额外回归，直接推送 GitHub 构建。沿用本会话已明确授权的临时公开构建，发布完成后恢复私有。
