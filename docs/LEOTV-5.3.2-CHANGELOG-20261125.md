# Leotv 5.3.2 更新日志

- 首页缓存上限默认 500MB，支持在个性设置中调整。
- 保存推荐资源、TMDB 匹配与资料缓存，启动先恢复轮播，再后台核对更新。
- 首页 15 项轮播并发匹配，已有结果及时显示，后续更新合并提交。
- 详情先显示海报、简介和评分，演员、季信息、选集缩略图、评论及合集并行补齐。
- 提前缓存详情最多五张高清海报；演员、选集及剧照图片按当前屏幕和附近屏幕优先加载。
- 图片更新保留当前画面，补充数据保留已有卡片，减少闪动和焦点中断。
- 增加并发 DNS 与共享连接池；图片首选 images.tmdb.org，慢响应或失败时由原域名接替，兼容完整 /t/p/w500 前缀。

保留 TV/手机、32/64 位四套 APK，沿用固定签名并支持覆盖升级。缓存命中可直接显示已有内容，首次冷加载速度仍受网络影响，实际效果由真机验收。
