# APK 独立 CSP 新主页：5.2.0-preview.1 / 601

用户要求新增分类排列方式，并明确：功能必须独立于 JAR 首页 UI/桥接，不论切换什么订阅、哪个 CSP 都适用；轮播取当前 CSP 首个分类的数据。个性设置的“新主页”默认开启，每次点击直接切换开启/关闭。预发行使用 preview 后缀，不占用正式 5.2.1 标签，正式 5.2.0 和最新版本指向保留。

## 数据与原生边界

NewHome/CspHomeData/CspHomePage 由 APK 管理生命周期、分类加载、分组排列、轮播和滚动。SiteFeed 读取原宿主当前站点与配置，并调用原 home/category 工作线，保留当前 CSP 的网络/解析协议。原 R8 将 E3.p/B3.p 的空构造内联消除了；构建覆盖层仅补回等价 public 空构造，原 call() 及其 homeContent/homeVideoContent/分类转换逻辑不修改，签名 JAR不进入 APK。

分类顺序使用当前返回的 class/types，不生成假的“AI猜你喜欢”等内容。每组最多 15 条，尾部有“更多”，组标题右侧也可打开；按可见区域加载后续分组，避免首屏加载所有海报。第一分类前 15 条中有效图片用于轮播，手机按竖图、TV优先后台/横图地址并使用横屏裁剪；站点只有竖图时不能凭空生成原生横图资源。轮播继续使用 APK DetailHero，取色衔接背景，资源图片走现有 CSP 图片缓存。

APK 只在自己的新主页显示期间覆盖原内容容器，原手机导航实例保留；菜单可切换站点、搜索、历史、设置或关闭新主页。原页隐藏后，JAR 自带主页不会取得当前可见首页位置；没有调用 JAR 首页桥。关闭开关、切到设置/追更或退出时移除覆盖并归还原容器。配置/站点身份与请求代次拒绝迟到结果，取消视图后不展示上一订阅的数据。

## 单分类窗口

CspCategoryActivity 是独立 APK 窗口，仅显示指定分类。采用与当前原网格相同的基本海报网格方向，手机/TV分别排布，包含该 CSP 的筛选值、继续分页与目录下钻；不显示其它分类。资源进入已保留的详情/播放器链路，索引型资源仍遵守全局搜索开关。页面背景携带当前海报色，不读取其它 JAR 页面。这个预发行是新排列的第一轮真机版，原实现的全部交互细节以设备反馈继续优化。

## 构建门禁和交付

新增四个 APK 源类；源码集合、原 p callable 的固定 SHA、允许变化清单、独立 Activity 和 R8 保留入口一并更新。原数据库、播放器、缓存协议、native 与两个 ABI 差别保留。preview/beta/rc 后缀被构建、草稿传输和最近 10 个预发行清理规则识别；正式发布仍使用纯正式版本标签。

按用户明确要求，不反复运行界面验证/回归测试；只做 API 23 编译、原样/声明变化、R8接口和固定签名的构建步骤，推送预发行交由手机/TV真机验收。
