# Leotv 5.1.10 滚动、详情页与设置修正

用户在 5.1.9 实测发现：推荐以外的分类无法滚到状态栏、滚动内容覆盖分类控件、上下渐变模糊不可见；手机个性设置因 NestedScrollView 多个直接子视图崩溃，TV 新设置复制了原两列组合；详情海报未铺到窗口顶端，TV APK 在手机上打开详情会进入竖屏。

- 全局取景每帧按实际可见区域选择滚动页，处理 ViewPager 缓存页仍处于 shown 状态的情况。各页的 viewport 借用保留到页销毁或窗口尺寸变化，避免切换分类反复重置列表位置。
- 保留原分页容器裁切，通过单独的上下绘制区域重现滚动内容。顶部过渡覆盖状态栏、顶栏、分类栏及内侧边缘，底部过渡覆盖底栏及内侧边缘；原分类文字、图标、按钮和选择 Drawable 在其上绘制，原生点击坐标与焦点仍由原控件维护。
- 软件取样遇到 HARDWARE Bitmap 时使用有界 CPU 副本缓存，绘制完成后恢复原 Drawable；窗口后台/销毁时释放缓存。缓冲与回调继续沿用 Choreographer 生命周期。
- 设置只复制 size 对应的单行控件，插入原滚动容器的唯一内容列，保留原设置对象、ID、事件、可见性和两列结构。新入口只有“详情页主题”和“TMDB 配置”；手机纵排、TV 同行左右各一项。
- TMDB Key 与域名在同一原生主题弹窗中配置，保存前同时验证、使用同一 SharedPreferences Editor 写入。取消不写入，恢复默认同时恢复两项，非法地址保留原值与弹窗；原 tmdb_key/tmdb_base 和详情主题偏好继续使用。
- 详情页单独设置透明系统栏及窗口铺满布局，海报起点为窗口顶部。TV 新 Activity 的 Manifest 和运行时均使用 sensorLandscape，与普通 TV 原声明一致；手机播放器的按视频尺寸旋转逻辑保持原契约。

验证覆盖 Android 6/API 23 与 Android 15/API 35 的设置结构、合并弹窗、保存/取消/校验/默认值、海报顶端坐标、TV 横屏；绘图检查覆盖缓存页切换、分类前景、上下模糊对比度、原按钮状态、壁纸、焦点和回调生命周期。硬件图片测试在宿主原生像素上模拟硬件专用标识，不代表真实手机 GPU 验收。

完整 APK 构建继续执行原样基准、所有代码/字段/注解语义、声明变更、保留资源和各 ABI 原生库审计。GitHub 输出四款固定签名 APK 并自动发布；Android 6 真机、真实站点、播放和设备视觉效果由后续验收记录确认。用户配置与签名私钥不进入 Git、日志或产物。
