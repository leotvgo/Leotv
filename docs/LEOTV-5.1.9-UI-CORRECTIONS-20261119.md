# Leotv 5.1.9 UI 修正

用户反馈 5.1.8 的分类边框、壁纸、上下栏、详情页和设置风格与目标不一致，要求完整对照 JAR 详情页，含全局/站点搜索、换源、线路、缩略图、相关推荐、演员、评论及播放进度。

- 全局层移除 ControlBackground，不再替换分类和按钮的正常、选中、激活、焦点、按下 Drawable；页面根背景也保持原对象和后续壁纸更新。
- 上下系统栏保持透明。手机列表使用 JAR NativeViewport 的原锚点补偿；完整 ScrollView 通过只读绘制扩展，保留原滚动区域和点击坐标，避免滚动内容覆盖顶栏。底栏范围始终取实际导航栏位置，两种滚动方向使用同一范围。
- 详情页面使用 JAR 的主题几何方法和影视库组合，手机/TV 在各自源码目录绑定客户端。原按钮、缩略图、站点菜单、重匹配、剧照、评论、演员详情和焦点导航组件保留；原控件与接口适配为独立详情控制器。
- 站点搜索仍调用原 B3.i/E3.i，目录调用原 B3.j/E3.l；站点管理写回原 Site.searchable/save，与宿主共用。长按在窄手机打开 SearchActivity，在 TV/宽窗口打开 CollectActivity。相关推荐/系列/演员相关作品保留原卡片与详情搜索流程。
- 追更按钮保留原外观，功能按用户要求暂缓接入；收藏继续使用原 Keep/History 配置空间。
- 重匹配使用原 DetailMatchPopup 和 MetadataMatchStore，更新海报、演员、剧集缩略图及相关条目。播放按钮使用原 DetailPlayButton.resume，读取已保存的剧集、位置和时长，返回后更新进度。
- 个性设置从原字号配置行复制层级、字体、颜色、背景和尺寸；选择/输入使用原 l4.b Material 构建器和原 dialog_title 等资源，保留正常/焦点及弹窗按钮样式。

布局与十个原组件的参考/迁入 SHA-256 记录在 detail/layout-provenance.json。API 23 两端编译、手机/TV 回归、全部主题渲染预览以及 32 位完整 APK 原样基准/变更审计作为本地门禁；四变体最终由 GitHub 构建、固定签名和自动发布。

本地最终核对通过手机和 TV 各 14 项详情检查、11 项上下栏/模糊检查，以及四变体原宿主接口门禁。两份完整 32 位 APK 审计中的全部编译输入 SHA-256 与待提交源码一致，原资源和原生库保留检查通过；完整记录见 [本地验证取证](../evidence/leotv-5.1.9-local-validation-20261119.json)。

测试使用虚构媒体与内存边界；预览是模拟渲染，不是设备截图。签名后的设备视觉、滚动、真实站点播放和性能验收由后续用户测试记录。原 APK、比较快照、原样基准、原生库、签名配置与用户运行数据保留。
