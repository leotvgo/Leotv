# 5.3.6 / 668 浪壳界面对齐与背景修复

用户以原版与 667 真机截图指出：主页按钮应打开右侧站点列表；当前版首页/详情无背景海报，卡片与字体偏大，分类/线路/选集底色缺失，全局搜索仍为旧界面。用户明确要求这些修复和八类新增漫画弹幕合并交付 668。

## 已确认的遗漏与修复

- 独立资源包使用系统 Resources 后未同步 TV 适配密度，Configuration 还会覆盖独立设置的 DisplayMetrics。现在按原版 960dp 设计宽度同时设置两者，限定到浪壳资源上下文；其他主题/手机保持宿主资源。使用独立 LayoutInflater 保留资源 Context，避免宿主 AppCompat 工厂替换为原 Activity 资源与密度。
- 原浪壳 `fq3` 会在运行时重建分类胶囊、线路、选集和控制按钮的底色/红色焦点，XML 并不是最终样式。新增 `LiulangStyle` 恢复相应默认参数，资源绑定记录具体目标；线路/选集换回原对应 selector，分组按钮恢复多列/原始/正序文案和顺序。
- 原 `HomeActivityV2` 的按钮短按经 `d30` 打开 `wr3` 右侧五分之一宽的站点侧栏。现使用原 `dialog_v2_site`/`adapter_site_simple`，排除隐藏站点、定位当前站点，并调用保留宿主 `HomeActivity.l(Site)` 完成真实切换。历史使用独立导航入口。上方主导航与原六项顺序对齐，追更继续可由设置项长按及原设置入口到达。
- 新增 TV 浪壳搜索 Activity，采用原搜索/键盘/词条/站点资源；左侧字母与注音键盘、原图标、输入法、热搜与搜索历史，右侧词条和下方按站点的横向搜索结果，保留完整关键词和分页。源请求复用保留 B3.i 搜索任务，取消和配置身份隔离；热搜/联想沿用原公开端点。导航、海报长按和原 Search/Collect Activity 入口均服从所选 TV 模式，其他模式不重定向。背景使用当前作品的有界模糊快照。
- 背景请求对相同进行中路径去重，资料渐进回调不再取消重启同一下载；首张成功图片立即可见，旧请求结果不会覆盖新作品。路径使用与现有 DetailHero 一致的图片路由判断，并记录失败类别；加载中或失败保留实际来源竖海报回退。横版标题槽排除纵向 logo，避免缩成小竖图；元数据行按原顺序显示来源年份/更新信息/类型/评分。

## 验证边界

新增独立 `research/liulang-ui-check`：实际编译 XML 的资源 Context、960dp 配置密度、背景/导航/卡片尺寸和分类底色；虚构图片的重复请求、首次显示、失败回退与旧结果隔离。该工程使用 Robolectric 4.18.1 以支持独立资源包，依赖只用于检查、不进入 APK。原 25 项 UI、矢量等价、漫画绘图、源码/API23/R8/原样与变化/native/固定签名继续保留。

最终与原版在所有设备上的像素、动画、真实站点返回及遥控状态一致性仍以真机对照为准；不以源码/资源链接成功代替运行验收。本版延续 5.3.6、版本码 668，保持八套产品及正式 664 下载。本次交付记录如下。
