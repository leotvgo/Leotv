# Leotv 5.3.6 / 669 浪壳 Android 6 与海报修复

用户真机反馈 668：其他主题 TMDB 海报正常，浪壳有元数据却无海报；启动出现空内容和大字“请选择站点”；详情/搜索切换露出旧背景；收藏/推送未跟随主题。随后授权 ADB 调试 Android 6.0.1、armeabi-v7a 电视，确认切换后连续启动崩溃，并要求完成验证后关闭电视。

## 确认原因和修复

- 海报：`ImageView.setAlpha(int)` 的取值是 0–255。原 `setAlpha(1)` 和整数三元表达式把图像设为 1/255 或 0，ViewPropertyAnimator 的 View alpha 无法恢复图像 alpha；因此 metadata/image 请求正常但图片不可见。统一使用浮点 View alpha，并在实际完整首页/详情上绘制蓝色虚构图片验证像素，回显及暂停后仍保持 image alpha 255。
- Android 6：真实日志根因是 `TV resource package unavailable`。该系统 PackageManager 对同包名复用宿主 Resources，忽略复制 ApplicationInfo 添加的 split 路径。增加独立 AssetManager，按宿主及 split、主题顺序加载且核对 cookie/布局标识；保持原资源命名空间和宿主 ID。已用电视上的独立资源探针验证四个实际布局存在并可解析；完整 APK 验证另记。
- 启动：站点尚未初始化时显示加载动画，隐藏无效标题/海报及空内容提示；真实请求完成为空或失败时才走已有空/错误状态。
- 切页：首页暂停只停止工作、保留最后一帧，取消 onPause 将整页 GONE 的处理；恢复时重新接续未完成图片。详情沿用当前海报快照，搜索直接使用同主题模糊背景，主题内窗口动画关闭。
- 收藏/推送及同类原生页面：只在浪壳 TV 模式接入当前海报模糊背景，保留原内容和点击；遮去旧壁纸、清除全屏底色，退出主题时恢复原状态。手机实现为空，不带主题资源。
