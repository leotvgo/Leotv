# Leotv 5.3.6 / 667 TV 浪壳全局迁移

用户授权依据：读取另一窗口的调查结论，将所选浪壳大海报首页、详情和全屏播放控制作为 TV 可选的「浪壳全局」模式迁入。入口为个性设置 → 新主页主题，稳定 ID 5；其他 TV 主题 ID 0–4 与手机 ID 0/3/4 保持，详情偏好不被覆盖。666 TV 快捷菜单修复继续保留。

## 原始资料与恢复方式

采用 261124 双 ABI 样本，来源与 24 类/14 项资源一致性依据见[调查报告](LEOTV-LIULANG-TV-GLOBAL-UI-FEASIBILITY-20261128.md)。原版选定布局及其资源依赖保存在 `detail/liulang/reference-res`，文件 SHA-256、选定 values 和原 APK 摘要在 `resource-lock.json` 中固定。

构建期按明确映射适配原 View 类名，Android 6 不支持的默认焦点高亮属性改为运行时判断；应用主题、资源编号和原 APK 资源表保持。独立资源包使用 `com.leotv.liulang` / `0x6f`，只包含资源，无 DEX/native；作为 TV APK 的两个声明资产携带，安装时使用系统 PackageManager 的资源加载 API，校验 SHA-256 后加载。手机不打包此资源资产。平台 TextView/ImageView 替代仅用于兼容 View 类型；原 XML 的尺寸、边距、颜色、drawable 与文本结构保留。

首页按原 `HomeActivityV2` 的横向分类/海报行、200ms 焦点加载延迟、前后各两项预取窗口、450ms/1.03 倍背景过渡恢复，使用当前站点的分类、筛选、目录、分页与去重。首页菜单沿用 Leotv 搜索/收藏/历史/直播/推送/设置/追更入口，原生站点选择继续负责切站。

详情使用原 `activity_detail` 资源和按钮/线路/分组选集布局；8 列 24 项、2 列 6 项分组，左右边界按同一行进入相邻分组。现有控制器继续负责详情请求、换源、第二层路径、续播、排序及失效提示。演员、剧照、评论、推荐、追更、下载及手动元数据匹配从“更多”进入现有完整详情区域，保留动作和数据。

播放保留原 `VideoActivity`、Surface、取链及各内核，迁入控制栏样式和选集面板。内核、解码、速度、比例、字幕、片头片尾、弹幕等控件保留原实例和动作，原生 O0/L0 继续选线路与剧集。浮层返回按选集→控制栏→退出处理，当前会话显式携带模式选择。完整/基础产品仍只在 MPV/VLC 档位上不同。

## 核对范围与边界

`check_liulang_ui.py` 固定 TV 模式、源资源闭包、API23、源码哈希、请求取消和原生播放器边界；原有首页布局回退和手机门禁继续适用于原主题。实际构建继续执行源码/API23/R8、原样语义、允许变化、原 ZIP/native、固定签名和完整/基础一致性检查。

原版部分方法无法直接反编译为可编译源码，迁入代码依据原 Java 阅读材料及 smali 契约连接已有服务；没有打入浪壳的同名 Activity、整个 DEX 或新的播放器库。UI 模式仍需用户对照原版真机验收，资源参数和静态检查不能证明所有分辨率、动画时序和遥控路径完全一致。

本版为 5.3.6 / 667 测试交付，正式 664 与 665/666 测试下载保留。实际交付已完成，详见下方记录。

## 资源兼容排查记录

两轮初始构建在资源链接阶段失败，Java/API23/R8 均已通过。第一轮是反编译 style 尺寸使用 -2 原始文本，第二轮是 XML 的 clipToOutline/paddingHorizontal 与 vector fillType 不在 API23 公共属性集中。已按等价行为转换：wrap_content；运行时 View.setClipToOutline；左右 padding；原历史圆环的反向内轮廓采用 API23 winding。历史图标实际 path 的 EVEN_ODD/WINDING 原生绘图逐像素比较通过，原始参考资源不改。

独立资源编译及完整属性检查已通过：102 个源资源文件、117 种输出 Android 属性、18 个编译布局、548 个 XML 引用、17 个运行时绑定目标和两个 ABI 的原控件构造。新增 liulang-resources 必需 job 在 prepare 前检查整套资源；实际每个 TV APK 还检查 R8 输出保留 XML 构造，发布时核对真实签名 APK 的两项主题资产，手机资产必须为空。
