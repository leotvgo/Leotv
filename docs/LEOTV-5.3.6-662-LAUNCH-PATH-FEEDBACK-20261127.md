# Leotv 5.3.6 / 662 启动图、路径单选与失效资源提示

## 修复范围

- 手机浮层旧判定把控件selected状态与标签等于父线路名也视为选择。子路径与父线路同名时，即使改选另一个路径也能出现双勾。层级菜单只读拥有者activated状态；路径持久化仍按配置/站点/作品/线路及路径名，真实URL相同也不影响单选。
- 路径发现原来仅一个线程，取消后仍未退出的站点请求能阻塞新线路。两条工作线程配合原有一个待执行槽，15秒有界等待、源/配置/代次核对、取消和销毁清理；过期结果不覆盖新选择。仅复用已返回的路径名称，不持久缓存临时地址或改变原播放取链。
- 路径发现使用与播放相同的CSP/API4/普通站点分发，但检查完整返回各路径，而非让播放中默认位置的usable判定提前丢弃其他有效路径。请求完成后所有路径实际地址为空才提示失效；请求异常/超时显示重试，不把尚在加载的资源判为失效。详情直接加载或手动选中资源返回空剧集也提示同一句话；元数据预览和自动找源的暂时空数据不弹失效提示。
- 启动画面沿用原启动图的白色头像和文字轮廓、方形坐标及比例，API21原生vector/layer-list居中显示，青紫渐变填满窗口。原桌面图标/banner和现有首页GIF不变。只替换现有compat_splash_screen_no_icon_background文件，不增加/重排资源ID与配置。TV的初始windowBackground及手机Theme.Splash引用同一图；实际页面在创建时恢复原窗口色，不把启动图当壁纸。
- Android12及以上第一段系统启动屏仍受系统图标尺寸限制；其退出时使用API隔离的反射监听衔接同一全屏图，250ms后移除，触摸立即移除，主页并行初始化。Android6不解析API31类型。
