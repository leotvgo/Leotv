# Leotv 5.1.15 手机状态栏下的内容滚动

用户反馈 5.1.14 壁纸可到窗口顶端，但内容看起来仍在宿主顶栏截止，希望卡片像详情海报一样从原生状态栏下滚出，其他布局大致正常。本轮继续修改后直接推送 GitHub 构建，由用户真机复测。

- 5.1.14 的淡出覆盖 0 至状态栏下沿 +6dp，其中状态栏上方大部分为完全不透明的宿主壁纸，实际遮住了进入该区域的卡片。手机淡出现在限定为窗口顶端 0–8dp，8dp 以下不覆盖；原生状态栏图标继续由系统绘制，卡片在其下方保持可见并向屏幕顶端滚出。没有重新引入顶部模糊或截图重绘。
- `NativeViewport` 记录借用前的本地上沿和 translation。布局完成后比较真实 `getTop()` 与应有的扩展上沿，仅在父容器没有落实负 margin 时以 translation 补齐；补偿 padding 保留卡片的初始位置。退出内容/切换分类恢复原 translation。该校正只在手机分支调用。
- 对不能借用 margin 参数的原生 ScrollView/NestedScrollView 根，解除该根自身裁剪，使未回收的完整子内容可画出其上沿；所有裁剪在离开内容时恢复。
- 手机分类归位后先等待一次原生布局，再记录目的分类的 viewport 基准，避免以恢复前的扩展位置重复计算偏移。保留既有归位、原生 AppBar 折叠、透明背景和前后层次。
- 手机窗口避让/根 padding、底栏、TV 绘制及详情/播放保持既有实现。版本为 5.1.15 / 525；只改变声明的 UI 覆盖类及版本资源，原 smali、数据库、站点协议、JNI/回移层、原生库与用户配置不变。

已读取普通 APK 的原布局与相关 smali，以及本机 API 23 的布局源码核对边界。未运行本地或 CI 回归套件；GitHub 执行四变体 API 23 编译、原样/允许变更审计、固定签名与发布检查。仍需用户真机确认推荐/其他分类的卡片经过原生状态栏区域、顶端淡出和初始归位，不将源码核对等同于设备验收。
