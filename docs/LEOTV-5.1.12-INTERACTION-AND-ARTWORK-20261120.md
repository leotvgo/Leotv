# Leotv 5.1.12 交互、渐变与播放器艺术字

本轮依据 5.1.11 手机实测反馈修正：新增设置首触只获得焦点、主题选择未生效、顶部清晰/模糊边界明显，以及推荐切换其他分类时底栏残留。用户明确要求改代码后直接推送 GitHub 构建，本地不运行验证测试，设备验收由用户完成。

- 手机新增设置不再请求触摸焦点，保留 TV 遥控焦点。手机选择弹窗调用原 o4.b 的原生单选方法 f，选择回调写入主题；已创建的详情页监听 detail_theme 变化并重新应用布局。
- 保持已有顶部范围，使用五档模糊半径和更平缓的强度插值，减轻清晰边缘到强模糊的突变。原全分辨率清晰底图和系统栏坐标继续保留。
- 取景增加 ViewPager 页索引、横向偏移及当前页引用的切换门禁，切换过程丢弃旧缓冲；内容重绘只进入当前可见页，避免不透明缓存页再次进入底栏取样。
- 详情加载沿用 HomeActivity 当前背景，仅在匹配完成且图片准备好后显示详情海报。标题、原线路及播放入口继续可用；没有 TMDB 图片时保留宿主背景作为兜底，不把元数据加载作为播放条件。
- 参考 JAR 的 PlayerTitleArt、PlayerOverlayAnchor、PlayerOverlayPosition 接入播放器左下角标题艺术字。详情传递已匹配 logo 路径；标志位于原 control 上方，随原控制栏显示/折叠，保持按钮绘制顺序与遥控/触摸事件，退出播放器关闭加载器和监听。

新增播放器源码列入 runtime-sources.json，编译仍以 API 23 为下限，原样审计与声明变更审计继续由 GitHub 构建执行；APK 使用既有独立固定签名。构建工作流增加默认开启的 run_validation_tests 输入，本轮按用户要求设置为 false，跳过模型与 UI 回归套件；后续默认仍运行回归。原 APK、原生库、数据库模型、用户配置及凭据保留。此次没有本地或真机运行通过的结论。
