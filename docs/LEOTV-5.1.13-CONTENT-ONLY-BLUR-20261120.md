# Leotv 5.1.13 内容页限定与播放衔接

用户要求上下渐变模糊只用于线路内容区，设置、播放和其他界面退出处理；手机顶部仍有明显横向分界。补充要求分类切换返回初始滚动位置，以及详情进入全屏播放时避免露出空宿主背景。本轮继续按要求修改后直接推送 GitHub，跳过本地和 CI 回归套件。

- 生命周期仅为 HomeActivity 创建内容处理器。手机进一步核对原 navigation 当前选中项为 vod，并要求分类 pager 可见；TV 要求 HomeActivity 的分类 pager 可见。其他 Activity 不安装该层，HomeActivity 内离开线路页恢复原背景、系统栏颜色/布局标志、列表参数和 padding，移除绘制层。
- 手机模糊过渡缩到系统状态栏下方 4dp。整块内容复制绘制也在边缘做 DST_IN 渐隐，与当前原生画面合成，避免清晰复制层的矩形边界形成横线；TV 仅在内容区启用。
- 分类索引变化时取消 viewport 的旧锚点补偿、还原借用参数，并调用原列表初始定位方法。手机 RecyclerView 的原方法为 i0(I)V，TV 为 scrollToPosition(I)V；原 AppBar 展开，返回分类不再保留旧位置。这些签名进入原 APK ABI 门禁。
- 详情转播放使用当前详情画面的缩略帧作为 Activity 衔接，播放器创建时使用同一帧作为窗口/播放容器的临时背景，避免先绘制空宿主背景。接收后丢弃静态交接引用，退出播放器清理交接；快照仅在内存，不写文件或日志，原播放器和控制栏继续运行。

四变体由 GitHub 执行 API 23 编译、原样和允许变更审计、固定签名及自动发布。本轮没有回归/真机通过结论；顶部合成观感、分类归位及两端播放衔接由用户实机复测。原数据库、配置、站点协议、JNI/回移层和原生库继续保留。
