# Leotv 5.1.21 透明导航与追更背景

用户在手机切到追更、直播、设置时看到底栏恢复原底色；追更页面使用独立深色渐变、状态栏有浅色断层、标题与管理操作重叠，而且没有原来的四个导航按钮。TV 追更页也需沿用宿主背景。

- 根因：GlobalChrome.disableContent 在离开线路内容时归还了导航背景。现在导航透明由独立控制器维护，覆盖手机 HomeActivity 的四个入口；保留原生选中和触摸反馈，线路渐变仍只用于内容页。导航不再加入线路模糊的借用背景集合，退出线路时保持透明。
- 追更页从手机原生导航保存菜单、图标、主题和文字/图标着色，使用同一个 BottomNavigationView 类重新创建四项导航。已核对原包只保留 Context/AttributeSet 双参数构造，新增对应契约门禁。非追更项回到已恢复的 HomeActivity 后再调用其原生选项切换，避免在暂停的宿主上提交页面变化。Activity 重建而内存快照不存在时，从保留的 menu_nav 资源恢复同样四项导航。
- CalendarBackdrop 只显示宿主当前壁纸/共享背景，不生成独立详情色渐变。HomeActivity 离开时优先保留 JAR 同步的直属背景层，其次保留原壁纸；ImageView 按中心裁剪铺满窗口。手机/TV均使用此逻辑，不改JAR核心。
- 日历窗口延伸至系统上下栏，系统栏透明。根层统一消费窗口避让，标题和内容避让原生状态栏，手机列表为底部四按钮与系统导航区留出空间，背景完整铺到顶部/底部。浅背景使用深色文字和状态栏图标，日期条、卡片同步适配。
- 手机标题/返回独占第一行，管理/今天/日历在下一行等分宽度，避免标题重叠。手机单列卡片明确为单列；TV标题与操作使用有界横排，保留自适应横屏网格、左右/上下焦点、月份选择器。窗口尺寸改变后重排网格。

版本5.1.21 / 531，API23、手机/TV及两个ABI保留。声明变化为上述覆盖源码、导航反射契约和版本资源；没有修改原宿主代码、数据库、native库、回移层或coos V6。本地完成API23 Java/D8与允许类导入、四变体接口审计；按用户既有要求跳过回归套件和模拟器，GitHub执行必要编译/审计/固定签名发布。实际背景、窗口避让、四按钮切换与TV遥控布局仍需真机复测。

原OK影视TV偶发详情接管排查按用户要求暂缓，本轮不更改或发布JAR核心。
