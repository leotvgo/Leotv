# Leotv 5.1.17 实时背景协议修正

V6 的 API23/35 专项发现 Android 禁止以系统资源 ID 设置自定义 keyed tag，相关核心候选未发布。配套协议改为普通 `View.getTag()` 的 Map：键 `leotv_page_artwork` 对应平台 Drawable；实际页面背景继续使用字符串标记 `leotv_page_backdrop`。APK 读取同一协议，避免新增或借用任何宿主资源 ID。

顶部淡出优先当前页面背景/轮播帧、海报扩展及同帧裁剪、切分类归还等行为沿用 5.1.16 的实现；当前最终 APK 为 5.1.17 / 527，配套核心 `v6.2026.11.20.1`。只有核心与 APK 都更新后才使用新接口。

APK 按用户既有要求跳过本地/CI 回归套件，执行 GitHub API23 编译、原样/允许变更审计、固定签名和发布；核心接口由独立专项及 V6 标准门禁核对。用户手机/TV 视觉验收另行记录。
