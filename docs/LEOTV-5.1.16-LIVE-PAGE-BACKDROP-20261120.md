# Leotv 5.1.16 当前页面的顶部淡出背景

用户反馈使用 JAR 新主页时，最上方淡出出现宿主蓝色壁纸细缝，要求自动跟随当前页面背景。本轮与 V6 `v6.2026.11.20.1` 核心适配一起交付，JAR 在 Leotv 中停用自己的上下栏处理。

- JAR 新主页将实际背景 View 标记为 `leotv_page_backdrop`，轮播 View 标记为 `leotv_page_artwork`，在 `android.R.id.background` keyed tag 提供平台 Drawable。仅通过 View/Drawable 公共接口通信，不按加固核心混淆后的类名反射。
- 手机在当前可见分类页查找背景，不采集其他缓存分类；顶部 0–8dp 淡出优先画当前页面背景和当前轮播帧。没有协议的普通页面继续使用当前宿主背景。
- 在原生绘制前以真实海报位置、滚动量和尺寸设置 Drawable bounds，核心将原生海报裁剪同步到同一个扩展帧。仅补绘海报上方的空缺区域，标题、按钮和卡片继续原生绘制；顶部淡出不会再覆盖固定蓝色壁纸条。
- 切分类、隐藏海报/打开子页及退出内容时归还旧 Drawable 的正常 bounds，恢复核心原羽化；背景/轮播实时更新，无独立截图或模糊缓存，仍使用现有显示帧回调。
- 版本 5.1.16 / 526。底栏、原生窗口避让、分类归位和详情/播放保持既有实现，只修改 `GlobalChrome` 覆盖类与版本资源。

APK 本轮跳过本地和 CI 回归套件，由 GitHub 执行 API23 编译、原样/变更审计、固定签名和发布。V6 的背景接口和委托行为另由核心发布门禁验证；两端视觉效果仍需用户真机复测。
