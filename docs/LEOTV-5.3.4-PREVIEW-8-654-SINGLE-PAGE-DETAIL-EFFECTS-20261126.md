# 5.3.4-preview.8 / 654：单页详情、首页整屏与动效可见性

用户实测653选集区域抖动加重，明确要求取消详情海报永远固定半屏，把所有主题按完整单页滚动，海报可以完全离开视口；同时要求修复TV光影/雷霆/影视库首页半屏留空、将影视库播放/评分/简介放回底部，以及增加能看见的双光点和无底板花瓣。此轮只落实这些授权修订，保留现有模块、播放器和新主页主题。

## 单页滚动

删除共用TvDetailScroll的半屏海报位移、pinnedHeight、内容裁剪与主视觉借用图层，移除TvDetailPage的pinHero注册和独立DetailSurface叠层。所有主题的海报、资料、选集和下方模块在同一ScrollView页面内滚动，焦点可见区域只使用视口边缘；海报及信息可完全滚出视图。原遥控顺序、同目标动画复用、首次回顶、返回、原模块顺序和手机触摸保持。

非影视库详情的下方渐变由内容自身背景承载，跟随内容滚动；影视库继续使用原地板色和首屏海报。不存在两个独立移动层互相裁剪的旧结构。

## 首页与影视库位置

TV光影、雷霆、影视库的主视觉使用完整视口高度，经典/极简和手机原高度保持；原生回收行显式同步主视觉高度，避免主题变化后保留旧行高度。TV首页的侧面阅读遮罩降低至透明叠加，完整海报可见，图片管线、数据源、回收和主题资料排列不改。

影视库信息组采用FrameLayout.BOTTOM定位。TV保留首屏全屏海报，信息/评分/简介/原播放操作组放在右下；手机放在海报底部。按信息组的实际宽度测量并以bottomMargin缓存，去掉18%/48%顶部偏移，保留原操作和长内容容纳策略。海报随整个页面滚动，不再固定半屏。

## 光点与花瓣

原双光点在没有抢到全局动画名额时完全不绘制，花瓣则先画后被缓存底板盖住。现在双光点即使静止也保持可见，取得光点组名额后沿底板路径绕圈；叠加花瓣改到缓存底板之后绘制，并避开文字区域。光点、花瓣、其他贴纸各有一个原帧驱动的动画名额，总上限3条，彼此不会因旧单名额被长期阻断，不建立独立线程或计时器。

无底板花瓣沿原普通文字渲染分支绘制：只画花瓣后返回原字形路径，不生成第二份文字位图，不覆盖原文字颜色/字体/阴影。独立花瓣及叠加花瓣继续按真实播放时间移动，暂停时停住。总特效比例、3/13光点及3/13花瓣权重、九类样式、八种头像、五种底板和多色组合保持，2MiB/64项缓存仍有界；没有整体上下跳动。
