## 源码修复

- 648 的 `ExoMediaPreload.Job.open()` 拒绝 `getAdblock()>0`。原 `Result.getAdblock()` 对未填写值默认返回 1，
  导致普通直链和新建的当前媒体响应也被提前关闭。当前媒体取原播放器已打开的 `D/q/A/F`，
  并标记为已处理的 `adblock=0`；下一集媒体使用独立响应，调用原 TV `C3/e.a0(Integer,String)` /
  手机 `F3/f.d0(Integer,String)` 的纯 URL 改写方法，保持原 m3u8 去广告/规则代理。
  原始取链响应、解析标记、字幕、弹幕、DRM 和实际换集的 Source.stop/fetch 流程保持。
  需要额外来源解析的地址仍只预取完整响应，不在后台操作前台 extractor。
- 新增 `DetailProgress`：用户进度按 `tv/movie + TMDB ID + 季数` 持久保存；源条目绑定另按当前配置 ID、订阅 URL、
  站点和资源 ID 隔离。详情首次确认元数据、历史进入和同作品换源均接入，已存在的共享记录优先于旧站点 History。
  首次迁移使用当前原生历史及已绑定、手选或可靠元数据缓存确认相同 TMDB 身份的旧记录，不按同名强行合并不同作品。
  换源按真实集数/名称查找实际剧集，缺集时不制造剧集或借用其他集的时间戳。
- 独立播放 Intent 携带作品身份及已有详情集数提示。原 A0 在重置播放器前采集旧集进度，在原 History.matchesName
  判断前恢复目标集的起播时间；接受原生 ready 事件后才允许保存新集，暂停、退出及五秒间隔保存实际播放器位置。
  原数据库表、migration、配置、收藏、排序、播放引擎和站点历史字段保留。
  原单条/按配置删除 History 同步删除共享记录并保存墓碑，避免旧站点记录复活；清缓存不删除用户播放进度。
- 手机下方内容外侧统一 16dp，剧照/推荐移除额外横向 6dp 内缩；TV 尺寸及手机现有海报/轮播主题源码不改。
- 新增原弹幕设置行“弹幕行间距”，沿用 Pro 的四档：8、16、32、40 原生像素；默认档 2 / 32 保持普通版当前观感。
  使用相同 `danmu_margin` 持久偏好和原 renderer 的配置更新/重排/绘制缓存失效流程，手机/TV 的已有字号、速度、透明度、
  显示范围和控制入口保留。

## 订阅动作与特效实现

用户指定的局域网订阅仅在忽略的 `.work/subscription-douban-20261126/` 读取取证，没有把订阅内容、JAR、凭据或设置文件加入 Git。
该 Douban 实现通常生成 `msearch:` 资源；启用预览时额外填写 `action=DOUBAN_SUBJECT|…`，
原资源动作分支将它交回订阅的 `Douban.action()`。`indexs` 被注释。
用户于本轮明确选择“保留订阅原来的预览动作”，因此没有拦截、删除或替换该动作。

Pro 参考文件为同级 coos/pro 的 `OK影视Pro_5.2.1TV.apk`，只读提取相关字节码。
其 `danmu_margin` getter 默认 2、限制 0～3；renderer 将四档映射到 8/16/32/40，普通版相应代码固定 32。
取证文件保存在忽略的 `.work/pro-danmaku-review-20261126/`，没有把 Pro 模块或播放器库移入普通版。

普通 TV/手机使用 DanmakuFlameMaster 的 `DanmakuView` 与混淆后的原文字绘制器、Bitmap 缓存。
TV 的 `I5/h` 使用 `Canvas.drawText`，弹幕数据 `H5/a.c` 为 String，不能直接以 Spannable 替换原文本协议。
可在原测量/绘制和缓存生成处按弹幕身份选择少量装饰模板，画成含原文字的图片，加入头像、描边或外框；
选择结果应按集/时间/内容固定，尺寸参与原排布，位图缓存有限且在 seek、换集、配置/内存清理时失效。
纯 Canvas 静态模板无需第二播放器或每帧生成图片；发光动画会增加持续绘制成本。
本轮已按追加授权实现九种模板：原霓虹艺术字、彩虹胶囊、流光边框、星光徽章、跳动表情、火箭，
再加入参考图头像贴纸胶囊、霓虹光球拖尾和花瓣。
使用本地 Canvas 绘制含原文字的位图；参考头像由用户提供截图裁切为 32×32 透明 PNG，
随程序数据嵌入，无网络图片或新播放器；默认开启，
按安装后保存的随机种子、原弹幕时间和文本稳定抽取 15%，支持 5/10/15/25/50% 调整。
原设置新增特效总开关、比例和动画开关；动画默认开启，流光/星光/表情/火箭/头像光点/光球拖尾/花瓣按原弹幕时钟变化，
同一时刻最多一条额外动画，暂停后没有独立计时器继续绘制。
原生测量后增加装饰尺寸，保留原字体及字号缩放，排布和碰撞继续使用原 retainer；
原可见性/时间/类型过滤及真实坐标确定后绘制，随后返回原统计路径，避免重复绘制原文字。
原颜色由所选炫彩模板替换，原透明度继续继承；多行、特殊定位、过长或超大弹幕保留原渲染。
缓存最多 64 项/2 MiB，换集/刷新/退出/内存清理释放位图；设置变化作废原测量/排布/缓存代次。
不新增帧回调；原 renderer 每帧绘制时使用缓存位图和少量图形叠加，内存不足暂回退普通文字。
实际颜色和流畅度仍由用户设备验收。
